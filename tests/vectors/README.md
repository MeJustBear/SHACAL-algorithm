# Тест-векторы SHACAL-1

Здесь зафиксированы эталонные («golden») тест-векторы, по которым тесты Этапа 4
проверяют, что поведение реализации не меняется.

> **Важно.** Это **не** официальные тест-векторы SHACAL-1. Реализация намеренно
> сохраняет унаследованный квирк развёртки ключа (слово `w[16]` остаётся нулевым,
> см. комментарий в `src/core/shacal1.cpp::expand_key`), поэтому её выход
> отличается от эталонного SHACAL-1. Векторы зафиксированы из самой реализации и
> служат якорем регрессии: принцип roadmap - «не ломать поведение алгоритма».

## Фиксированные входы

| Параметр    | Значение |
|-------------|----------|
| Ключ (64 байта) | байты `0x00 0x01 … 0x3F`, т.е. слова `00010203 04050607 … 3c3d3e3f` |
| IV (5 слов) | `a0a1a2a3 a4a5a6a7 a8a9aaab acadaeaf b0b1b2b3` |
| Раундовые константы | дефолтные SHACAL-1: `5a827999 6ed9eba1 8f1bbcdc ca62c1d6` |
| Сообщение (режимы) | 50 инкрементных байт `0x00 0x01 … 0x31` |
| Блок (примитив) | слова `00010203 04050607 08090a0b 0c0d0e0f 10111213` |

Точные значения см. в [`shacal1.vectors`](shacal1.vectors). Те же константы
заданы в коде тестов (`tests/common.hpp`), а файл здесь - человекочитаемая копия
артефакта этапа.
